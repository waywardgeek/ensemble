### What changed and why

The Agent owns its pause gate as a mutex/channel pair. Dispatch starts only one
call at a time; a paused boundary waits outside the actor while hints, interrupt,
and real worker reports continue through its existing mailbox. Cancellation wakes
the boundary waiter. An unpause from any client releases the same Agent gate.
No per-tab ownership or veto was introduced. The public root now offers identified
observer subscriptions. ToolDispatched/ToolFinished surround real dispatch/report
boundaries; TurnEnded is explicitly display progress, not request acknowledgement.

Parser IDs remain response-local for parser callbacks. The actor allocates
Agent-lifetime artifact identities for observations and stores them on response
parts so final replay addresses the same streamed cards. This avoids collisions
across model rounds/turns without changing provider request IDs or signed content.
History suffix snapshots deep-copy under its existing lock. The GUI combines a
current event-log view and accumulated partials under its own handoff lock. It
projects real facts for both live delivery and reconnect, clears finals from the
partial map, orders active partials by identity, and keeps the fixed last-hour OR
100-renderable-event window. Replay is one queued batch; it cannot silently lose
older cards merely because the live buffer holds 256 batches. Socket writes and
logging stay off the observer; shutdown joins writer lifetimes. No disk restore,
new persistence format/framework, settings workbench or sub-agent work was added.

The optional `main/gui` module consumes only public core interfaces. Its command
constructs one Ensemble/Agent and submits both browser and human terminal input
to that Agent. The original headless command remains unchanged. The page has one
ArtifactScroll, safe DOM-based Markdown subset, JSON arguments, ANSI colours,
compact tool cards, readable result text and diff-line treatment for edit results.
Long cards retain their full values behind an expander. Thinking is collapsible.
Native speech queues phrases from streamed thinking/text, abbreviates dispatches,
keeps results automatically silent, and reads every card's full content on demand.
Both native error and end advance the queue; empty-input Escape also works while
a speaker button holds focus. Typing and speech produce edge-triggered global
pause commands. Explicit unpause in another tab is never vetoed by stale local
state, including on reconnect.
