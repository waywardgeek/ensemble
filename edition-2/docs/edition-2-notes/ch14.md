## Correction round 1: end the peer's whole lifetime on EOF

The independent [initial review](ch14-code-review.md) found the sole blocker in
new peer shutdown. Its initialized idle control exited 125 ms after EOF, while
an outstanding 4000 ms sleep retained the process for 3865 ms. Closing Chrome
stopped browser waits but did not cancel Node's timer. Since the actual Go client
closes stdio and waits for the peer before Agent shutdown, a finished/expired
request could still wait arbitrarily long on that child. The earlier mutation
cleanup fix did not cover this case; preserve the original measurements in
`reviewer-peer-eof.json` and the initial submission at `4a7816a`.

owned process also ends its pending timer. Normal sleep is unchanged while its
session remains open. No sleep cap, new core API, configurable timeout or generic
cancellation framework was introduced; Go production and speech processing remain
unchanged.

public virtual-user executable, Agent jobs and MCP. Only the external provider
