### Implementation and design choices

- Kept translation in the existing Engine spoke rather than introducing a sibling
  package solely for the SSE reader. `Engine.Parse` is the single public response
  seam. Vendor stream readers assemble the provider message and reuse the existing
  semantic decoders for parts, provenance, canonical arguments and usage.
- Parser callbacks report actual vendor fragments. Anthropic uses block indices;
  OpenAI reserves zero for text and maps tool index `i` to `i+1`, so a tool arriving
  first cannot collide with later text. Gemini continues adjacent frame-leading
  text only when its thought flag matches. IDs restart for each response.
- The actor remains the sole history/orchestration owner. Workers queue deltas
  with the current turn token; completed response facts and parser-selected IDs
  return together. After storing the response, the actor publishes the stored
  parts, including history-assigned missing call IDs. Tools still execute only
  finalized, complete arguments. `AskWatching` uses this same actor path.
- Root-owned `APILog` writes one JSON trace record per frame or plain response.
  No auth headers or URLs enter the trace; configured-key reflection is redacted
  before writing or forwarding frame callbacks. The terminal uses unbuffered file
  writes for immediate delivery; its observer queues slow output without blocking
  the actor. Reply text uses stdout; reasoning, arguments and hint acknowledgments
  use stderr. `x/term` detects actual terminals before adding colour.
- Added `DisableStreaming`, explicit model stream capabilities and the two public
  environment conventions. Unknown models stay usable for text without streaming;
  media refusal remains separate. Enabled reasoning requests only for declared
  reasoning-capable models, in both streaming and disabled modes, so the opt-out
  changes delivery rather than requested content.
- Retained canonical final tool arguments from earlier chapters. Their streamed
  JSON fragments are displayed verbatim, so whitespace can differ from the
  authoritative canonical final arguments; the final part retains the same ID.
  This follows §7.8's distinction between transient display and authoritative
  content. Text and thinking fragments reconstruct their corresponding text.
- The external `ch07` module builds one Agent and one observer, reports per-kind
  counts, finalized-part counts and first-delta latency, and supports
  `CH07_NO_STREAM=1`. A short core README documents human CLI use. No GUI,
  persistence, pause, skills or sub-agent functionality was added.
