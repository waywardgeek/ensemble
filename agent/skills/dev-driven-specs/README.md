# Development-Driven Specifications skills

Imported from https://github.com/waywardgeek/dev-driven-specs for the Workflows
chapter development trial. The upstream repository remains the authoring source.
The five imported SKILL.md files are byte-identical to their source. Ensemble's
existing visible-reasoning skill supplies that dependency; no second reasoning
skill is imported. Links to ../visible-reasoning/SKILL.md in upstream manuals
refer to that shared dependency rather than a duplicate in this directory.

Importing files does not activate instructions. Dynamic imported-skill discovery
is under development; these files are not claimed active in the running Agent.
