### Implementation and choices

Agent retains its single serial dispatch funnel. Every ordinary call, including
unknown tools and file operations, gets a job/file/running event before its
handler runs. Only the four explicit supervision definitions omit a job. Agent
owns the jobs collection; each job retains its collection parent; Ensemble
allocates handles across its Agents. Shared records/interfaces stay in common,
job behavior in `internal/jobs`, tool argument/command behavior in `internal/tools`.
The call context retains its actual Agent and exposes Engine through that owner.
No spoke imports another implementation spoke; the separate GUI module is retained.

A job owns its writer, cursor, status and optional process. Its mutex coordinates
output, status and notifications. Completion and kills wake waiters; a late
handler result cannot change killed into done. Process launch transfers completion
to the PTY reader; dispatch returning never closes an active process's output.
Kill sends SIGKILL to the process group and reaps the shell. A contained Go-only
job reports that Go cannot stop its goroutine. Shutdown runs before the final
log save, including error exits from the live input loop.

Reports preserve small first results, otherwise supply status and unseen output.
Truncation keeps a head and tail, with exact omitted/total bytes and locator;
the cap bounds payload bytes, with report/marker text additional. Disk output is
complete. `read_file`'s former implicit 32 KiB cap is replaced by dispatch's
16 KiB cap; its explicit `max_bytes` and line ranges remain available. A completed
job stays waitable. Patterns match only unseen bytes. Matching reads that unseen
span from disk; this is not a claim of bounded regex memory. Redaction preserves
the output Ref as result metadata and stubs without rendering a blob attachment.

Limits are numeric seconds, regex and byte cap with defaults → pending → explicit
precedence. A pending setting is consumed even by a setter or invalid call, and
its values are disclosed in the consuming result. `send_input` submits a line,
adding a missing newline. PTY output merges stdout/stderr, retains echo,
normalizes CRLF across read boundaries, uses TERM=dumb and 50×200 size, and appends
`exit_code: N`. There is no fallback to pipes. The dependency is
`github.com/creack/pty v1.1.24`; the optional GUI module records its transitive sum.

`Config.Workspace` supplies the default shell directory; the CLI exposes the
launch-time `ENSEMBLE_WORKSPACE` setting and defaults to its launch directory.
File tools retain their Chapter 3 path semantics. `Config.DataDir` independently
supplies job storage; CLI uses `cr`, library defaults distinguish Agents beneath
`cr/agent-N`. Relative command cwd resolves against Workspace; nonexistent cwd
fails. Only a nondefault override appears in job metadata/report. No sticky cwd,
watchdog, deadline, mailbox, interruption machinery, recovery wrapper, MCP
connection or extra tool was added. Shell credential filtering remains intact.
