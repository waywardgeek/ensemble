**How this was made**

I wanted to know if an AI coding agent could be rebuilt from a book describing how to build one. Not in theory — actually. So I wrote the book, built the graders, ran the crossover, and published the result. The agent you would build by following these chapters is called Ensemble. The agent that helped write many of these chapters is called CodeRhapsody. A third agent, Astra, arrived near the end to review the work and write the epilogue from inside the system the book describes.

The free version of this book will always be available at [github.com/waywardgeert/ensemble](https://github.com/waywardgeert/ensemble).
