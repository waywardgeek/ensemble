intelligible paired tool states, stable reading, recorded timestamps and explicit
workspace work-product offers. History, Jobs and the Agent Sandbox retain their
existing ownership; the GUI projects their facts rather than creating another
conversation or file authority.

## Implemented increment: snippet copying

The source candidate now supports logical-payload copying for explicitly closed
assistant code fences. [Chapter 7](chapter-07.md#copy-the-logical-code-not-the-preview)
teaches the contract at the original rendering construction point. Its focused
browser verification includes denied clipboard access and stable streaming
interaction. This is one increment, not completion of this chapter's exercises,
public grading or student reconstruction. See the
[development evidence](../docs/edition-3-notes/artifacts-and-actions.md).

## Implemented increment: recorded observation state

Tool cards distinguish Result returned from the Job's state when observed.
Typed recorded metadata supplies the state and optional exit code; prose does not.
[Chapter 7](chapter-07.md#74-truthful-tool-cards) teaches the distinction at the
projection boundary. This is not a live Job monitor.

## Implemented increment: pairing and stable reading

Explicit call/latest-result navigation now uses the projected call relationship.
Tool-card controls retain focus, expansion and download feedback during updates;
selected text defers rendering and focused readers retain their pane position.
Detached controls cannot navigate through stale card objects. The focused
actual-page tests and two deliberate defects verify this presentation increment.
Public grading, student reconstruction and human usability acceptance remain open.

## Implemented increment: recorded timing

Recorded fact times now travel through retained Context and snapshot replay;
monotonic dispatch-to-return durations describe foreground observations, not Job
runtime. The foundations are taught in Chapters 2, 4, 7 and 10. Focused core and
projection checks pass, as do six browser suites and347 shared regression groups.
Timestamp-now and duration-zero mutants fail their intended assertions. Public
grading, student reconstruction and human acceptance remain open.

## Implemented increment: work-product source candidate

The candidate now has explicitly granted file offers, typed retained metadata,
Agent-owned cancellable copies and a guarded browser download route. The human
clicks to transfer current contents; no frozen store or automatic transfer is
created. Offers expire on Agent destruction or restart. Limits are 64 MiB per
transfer and 64 offers per Agent lifetime, with refusal rather than eviction at
the offer cap. Image-input and Job-output limits remain separate.

Focused ownership, grant, replay, transfer-lifetime and real HTTP tests pass.
Seven browser suites, truncated/stale-download negative controls and 350 shared
regression groups pass. Explicit client-abort, mount-stop and replay-cancellation checks also pass. Full
teaching, named public grader,
exercises, student reconstruction and human acceptance remain open. This section
is an increment record, not a completed chapter specification.
