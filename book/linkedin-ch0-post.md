written as prose, corrected by the coder who built it. Graders

decorative. Parity checks prevent regressions across chapters.

from Chapter 1, scoring 100 on every grader. Better model, better
agent. New capability in the field? Write a chapter. Next agent
has it.

At some point, the agent you built helps write the next chapter.
