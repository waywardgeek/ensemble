## D1: Bound attempts and retained evidence separately

Accept the Engine-owned diagnostic child and a separate stream per foreground,
compression and judge purpose. Observe the exact body at actual transport handoff,
after durable admission. A render, failed admission or reconstruction advances no
stream. State that a locally started attempt does not prove delivery or billing.
Retain identity for accepted admission that never reaches transport so that a
storage/cancellation failure cannot be mislabeled as a sent request.

Recommend a current-route baseline per purpose, cleared on route/model/funding
connection change, with an explicit reset reason. Do not store account identifiers
to achieve that separation; a local opaque connection generation is enough.
Configuration or projection changes within that route should normally remain
comparable and explain the change. Clearing on every configuration edit would
hide exactly the prefix changes the chapter wants to expose.

The draft must choose numeric per-body, aggregate-memory, export and summary
bounds. A useful concrete starting choice is at most two 8 MiB bodies per purpose,
three purposes, with no cross-Agent cache: 48 MiB of retained body data per Agent.
This is a reviewer sizing proposal, not a provider limit or final requirement.
An oversized attempt records bounded metadata and a gap, clears its body baseline,
and cannot silently compare the next request with a nonadjacent old request.
Bound temporary parsing allocations and export work as well as retained bytes.

Export an immutable owned pair with a manifest naming both attempts, byte counts
and digests. Publish the manifest only when both files are complete. Keep exact
bodies separate from annotated views. Disk failure cannot stop ordinary inference,
but must fail an evidence action that promised capture. The ordinary status view
contains no request text. Retiring source clears affected in-memory body copies;
explicitly exported receipts are separately selected artifacts with a stated
lifetime, never resume authority.

instrument's own status. Byte equality cannot diagnose a remote cache miss alone.
