# Planned real-interface coverage (before paid runs)

All demonstrations use a committed runtime source revision, complete nonempty Go/module source manifest, recorded executable and launcher hashes, and safe raw PTY transcripts, event logs, request-body captures and retained job artifacts. Discovery reads only necessary API-key fields from the authorized settings file; keys remain in memory/child environment and never enter argv or receipts. Capture relay retains bodies only, never authorization headers. Local fake fixtures validate changed capture/replay adapters first.

For each of Anthropic Messages, OpenAI Chat Completions and Gemini generateContent:

1. Actual human `chat` PTY: `/help`, idle hint refusal and idle interrupt acknowledgement; `/ephemeral` before work; ordinary prompt asks run_command with a 15-second delay and a 20-second report wait, producing a visible marker. Wait for tool_called in attributed durable log, type `/hint` changing final answer, observe immediate receipt, then observe actual answer. Check the hint in the next captured request and exclusion from the already-sent body, and ephemera consumption/replay bytes separately.
2. Same human PTY: start a second command with a long wait, submit an ordinary queued prompt (distinct accepted request ID), refuse busy `/ephemeral` and `/redact`, then `/interrupt`. Observe one interrupted completion with paired accepted calls and the queued prompt's own real answer. Later ask the model to inspect the still-owned job, then stop it by handle. Inspect history, usage, terminal event and artifact; do not infer provider streaming from nonstreaming observations.
3. Same human PTY: launch a managed command with short report delay and ask for no further supervision. Observe its final answer while the job runs; `/quit` must kill/drain it and record shutdown. Separate fresh human PTY: submit two ordinary prompts then EOF; both finish normally before usage/cleanup. These are human-mode terminal runs, not JSON input.
4. Public `examples/workflow` with author/editor/reviewer Agents, per-role instructions/tools/logs and reliable handles. Inspect actual draft creation/edit and actual reviewer completion. No library role special case.
5. Public `examples/workflow collection` with two Agents and separate logs: queued cancellation makes no HTTP/log turn, both handles complete before one collection drain, returned results preserve declared order, exhausted repeat is empty, handles and a second collection stay readable.

Deterministic local barriers supplement timing-sensitive paths: HTTP cancellation/stale worker discard; active caller cancellation and queued cancellation; independent canceled handle/collection waits; report supersession cursor accounting; all ready versus staggered collection drains; overflow with no lost reply; shutdown of active/queued callers and managed processes; nonkillable local function truthfulness; sixteen-request bound and actual append-time Gemini call identity. Provider HTTP cancellation is not claimed live if control lands during a report wait.

Replay verifier preflights all source-set and binary/launch identities before any derived write, reconstructs each request from its exact prefix and captured configuration, and compares bytes with raw wire-body receipts. Local negative controls remove a hint and reject mismatched/incomplete source or binary identity while preserving originals. Evidence-only repairs will not repeat paid runs.
