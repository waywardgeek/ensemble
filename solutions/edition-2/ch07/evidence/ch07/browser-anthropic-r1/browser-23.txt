---

Recorded tool result vs. running process (~100 words)

A recorded tool result is a completed, static artifact — the file was written, the read returned its bytes, and those results are now frozen in the conversation history as plain text. The Agent and any client can reference them at any time without re-executing anything. A running process, by contrast, is a live, stateful entity with a PTY, a process group, and ongoing output that accumulates over time. It consumes resources, can block or fail mid-stream, and requires polling or waiting. The key difference: a tool result is an immutable snapshot already in the record; a process is a dynamic computation still unfolding outside the history.
