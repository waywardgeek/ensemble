# Edition 3 source-only solutions

These are the preserved C# chapter endpoints. **Current application development
belongs in [`../agent/`](../agent/), not in an endpoint.** The V2 solutions were
archived in [`../edition-2/solutions/`](../edition-2/solutions/); V1 remains under
`../edition-1/solutions/`.

Endpoint names retain their historical numbers and contents byte-for-byte.
They were not renumbered when the current manuscript became Chapters 00–26.
See the [mapping in the book README](../book/README.md#sequential-manuscript-numbers-and-historical-endpoints).
The original paths in snapshot READMEs and evidence describe their creation;
use the current root README for active build and launch instructions.

The `evidence/` directory preserves the Edition 3 evidence files moved with these
endpoints. Broader scoped results and temporary artifacts are indexed in
[`../docs/edition-3-csharp-progress.md`](../docs/edition-3-csharp-progress.md).
